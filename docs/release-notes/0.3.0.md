## What's new in 0.3.0

- **13 languages, on demand.** French, Spanish, German, Italian, Portuguese, Russian, Chinese, Japanese, Korean, Hindi, Arabic and Dutch are now optional languages next to English (English is the only one on by default; if you already use French it stays on). Add the ones you need under **Settings → Languages**: each downloads only its small reference voices (about 1–2 MB), because the voice models are shared. If a language needs an engine you have not installed, the app tells you which and how big it is; nothing is downloaded without your say-so. Removing a language deletes its voices.
- **Better Chinese, Japanese and Korean.** Audio is no longer cut short for scripts that pack more speech per character.
- **Language-aware everything:** detection, chapter headings, numbers and abbreviations, sentence splitting, the speech check, and the spoken title and credits.
- 22 new licence-checked reference voices (credits are shown in Voices).

**Update the engine too.** New languages need the updated engine. Re-run the installer once (it updates in place):
```bash
curl -fsSL https://raw.githubusercontent.com/antoine-debroye/audiobook-converter/main/scripts/install-engine.sh | bash
```
The text rules for the new languages have not been reviewed by native speakers yet; please report anything that sounds wrong.
