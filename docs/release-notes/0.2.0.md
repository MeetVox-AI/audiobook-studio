## What's new in 0.2.0

- **Automatic updates.** Audiobook Studio now checks for new versions once a day, downloads them in the background and installs them the next time you quit. Updates are signed; the app only accepts ones signed with the project's key. Turn it off, or check now, under Settings → About.
- **Terms of use.** The app shows short terms on first launch (lawful use only; you are responsible for what you make; no warranty or liability) and lists the licence of every model and library under Settings → About.
- **Redesigned for macOS 26** with Liquid Glass, a readable dark mode and alignment fixes.
- **Delete cloned voices** you no longer need.
- **ffmpeg is found** even when the app is opened from Finder.

If you are on 0.1.0, install this version by hand once (open the DMG, drag the app to Applications). From here on it updates itself.
