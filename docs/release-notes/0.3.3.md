## What's new in 0.3.3

- **Your voice in more languages.** **Add My Voice** now offers every language a cloning engine can speak (with Qwen3-TTS: English, French, Spanish, German, Italian, Portuguese, Russian, Chinese, Japanese and Korean), not only the languages you have turned on. Each one says whether it is installed; if it is not, the sheet says so and turns it on (downloading its small voices) when you add the voice.
- **Clean up a recording.** Two optional boxes in **Add My Voice**: **Voice isolation** removes background noise and music and keeps the voice (DeepFilterNet3, 8.7 MB, MIT), and **Voice enhancer** restores clear speech (MossFormer2-SE, 110.7 MB, Apache-2.0; slower). A model you have not downloaded yet is fetched first, and the sheet says so. Both appear under **Models → Voice clean-up**, where you can also remove them.
- **Change a voice's recording without deleting it.** Right-click one of your voices (or open **Transcript and credits**) and choose **Change Recording…**: load a new file, or run the current one again with other clean-up boxes. The voice keeps its name, language and the places it is used. The transcript is kept when the cleaned clip is as long as before; otherwise it is transcribed again, so check it. To make this possible the app now keeps the first minute of each recording you add. Voices added before 0.3.3 have no saved copy, so the first time you change one, choose its file again.
- **Clearer error messages** when adding or changing a voice: plain sentences such as "Could not read this audio clip", without technical prefixes.
- **Fixed:** opening **Jobs** with no conversions made the sidebar disappear, and could crash the app.
- The app's links and the installer now point at the project's new home, `github.com/MeetVox-AI/audiobook-studio`.

**Update the engine too.** Voice clean-up and Change Recording need the updated engine; with the old one, ticking a clean-up box fails. Re-run the installer once (it updates in place):
```bash
curl -fsSL https://raw.githubusercontent.com/MeetVox-AI/audiobook-studio/main/scripts/install-engine.sh | bash
```
