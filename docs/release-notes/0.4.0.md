## What's new in 0.4.0

- **A new default narrator: ZONOS3-Mini.** 44.1 kHz, 25 built-in voices in nine languages, and cloning in all
  thirteen. It replaces Qwen3-TTS as the default for English, French, Spanish, German, Italian, Portuguese,
  Chinese, Korean and Hindi, runs about three times faster than listening, and is **1.4 GB instead of 6.2 GB**.
  Qwen3-TTS stays available (it carries native English, Chinese, Japanese and Korean presets; Voxtral
  remains the only engine with built-in Dutch and Arabic voices).
- **A studio-quality option: VoxCPM2.** 48 kHz and the closest match to a reference voice, for cloned narration
  only. It is about 1.7× slower than real time, so it is an opt-in choice, not the default.
- **A better speech check for eleven languages.** Qwen3-ASR 0.6B now listens back in German, Spanish, Italian,
  Portuguese, Russian, Chinese, Japanese, Korean, Hindi, Arabic and Dutch; English and French keep Whisper,
  whose thresholds were the only ones calibrated on real narration. Both are offered on the setup screen as
  the optional quality check, and the check falls back to Whisper when Qwen3-ASR is not installed.
- **A smaller first run.** The default download is about 7 GB instead of 12 GB. The free-space check dropped
  from 12 GB to 8 GB.

Your existing audiobooks, voices and settings stay. Conversations started before the update keep using the
engine they were started with; new books use the new defaults. If you want the old narrator back, choose
Qwen3-TTS in Voices, and it will keep being used for that language once you save it as the default.

The speech-check thresholds for the new languages are the same as before; they were calibrated for Whisper,
so the app still flags a few more chunks than it needs to until the new recogniser is calibrated on real
narration. Reports of false "words missing" warnings are especially useful.
