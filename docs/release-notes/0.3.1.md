## What's new in 0.3.1

- **Privacy policy.** Audiobook Studio collects nothing: no accounts, analytics, telemetry or crash reports, and narration works fully offline. The first-launch pop-up now has two short pages (Terms of use, then Privacy) with one "I Agree"; because the terms changed you will be asked once more. The full policy is under Settings → About and in `PRIVACY.md`, which names every website the app can contact (GitHub, Hugging Face, the Internet Archive, Homebrew, the Python Package Index). Library telemetry is switched off.
- **Clearer first-run setup.** Choose Quick, High quality or Very high quality, each with its exact model, download size, measured speed and a plain-words licence. Your languages decide which models are needed: for example Dutch and Arabic require Voxtral, and Russian, Chinese, Japanese and Korean require Qwen3-TTS, which are then selected for you. Totals and free space are shown before anything downloads, and personal-use-only models need one acknowledgement.
- **French is now an optional language** like the others (English is the only one on by default; if you already use French it stays on).
- Language cells in the setup are all the same size.

Updating the app updates itself; to refresh the engine too, re-run the installer once:
```bash
curl -fsSL https://raw.githubusercontent.com/MeetVox-AI/audiobook-studio/main/scripts/install-engine.sh | bash
```
