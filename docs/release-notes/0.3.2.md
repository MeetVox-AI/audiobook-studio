## What's new in 0.3.2

- **Friendlier first-run setup.** The setup now checks Apple's developer tools before it starts. If the Xcode licence has not been accepted (which makes `git` and Homebrew refuse to run), or the command line tools are missing, you get a plain "One thing first" notice with the exact steps, a **Copy Command** button, **Open Terminal** / **Install Tools**, and **Check Again**. If the install still stops for this reason, the same notice replaces the raw error, and **Try Again** re-checks first.

Updating the app updates itself; nothing else changes.
