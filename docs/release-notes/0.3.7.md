## What's new in 0.3.7

- **The new voices now reach every Mac.** Version 0.3.6 added 220 new reference voices (36 French narrators, about 30 each for Spanish, Portuguese, Russian, Dutch, German and Italian) but did not tell the app to update the voice engine, so the Voices screen still showed the old, short list. 0.3.7 does: the engine updates itself (silently at launch with automatic updates on; otherwise the banner at the top offers **Update**). Your voices, models and audiobooks stay.
- Add a language in **Settings → Languages** to get its voices, then star the ones you like and switch on **Favourites** to hide the rest.
